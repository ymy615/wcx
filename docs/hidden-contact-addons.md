# 上游密友功能增补

基于上游 v336 `8b22739b23848b7856ebdcb2c97e21f90144d3c7`。保留上游 `HideContacts`、各隐藏面、通知、定时、搜索指令、分类总开关、名单和设置位置，仅增补下列功能。

- **离开对话恢复隐藏**：从任意对话返回主页时恢复，进入对话时不恢复。
- **离开主页/切走微信恢复隐藏**：进入其他页面、按 HOME 或切换应用时恢复。对话及联系人资料页作为导航例外，避免从通讯录打开资料就隐藏。两个开关独立保存，已隐藏时不重复提示。
- **圆点提示 / 底栏字体加粗**：原生未读状态与新消息共同驱动；打开对应密友对话清除，打开其他对话不清除。为支持真实未读状态，开启这两项中的任意一项时，上游隐藏列表更新钩子不再自动标记联系人已读。关闭两项后保留原上游行为。
- **密友显示状态提示**：临时显示时在同一位置显示绿点，恢复隐藏后按真实未读状态决定是否显示红点。绿点不消费未读记录。
- **操作提示**：显示、恢复隐藏、加入、移除文字均可编辑；开关关闭时不提示；提示沿用约一秒的短时显示。
- **会话列表长按添加 / 通讯录长按添加**：沿用微信原生菜单，增删同一份上游名单。菜单显示文字支持两处分别设置加入和移除文字；通讯录留空时跟随会话文字。不会另建旧版密友名单。
- **朋友圈查询增强**：沿用现有朋友圈分类和开关，恢复微信 8.0.79 原生个人相册兼容与缓存查询增强。仅展示本机仍保留的缓存，不能获取服务器未提供的内容。

上游三击监听只在主页创建时绑定，运行中开启功能会错过绑定。本分支在开启时查找当前主页，并在返回主页、标题重建后补绑；三击时间间隔可配置，沿用原维护版的设置键。

附带修正 DEX 可选方法占位识别：比较完整方法描述符，防止将解析失败的占位入口当作真实的通话/菜单/相册接口。未增加其他旧版隐藏功能，也未替换上游隐藏引擎。

新增选项沿用旧维护版对应设置键，已保存的开关和自定义文字优先；不存在配置时，两个恢复开关、红点、绿点、操作提示及两个添加入口默认开启，加粗默认关闭。上游“隐藏联系人”和“三击标题切换显隐”原开关保持原值。

构建：在 `codex/v336-secret-addons` 分支运行 `./Build-UpstreamAddons.ps1 -BuildOnly`。产物输出到本机 `D:/projects/VX/output/maintenance`，版本名 `v336-upstream-addons`；沿用本地维护签名，不能直接覆盖不同签名的上游安装包。

编译、签名及静态注册检查不代表实机通过。手机验收应覆盖运行中启用三击、两个恢复开关四种组合、真实未读红点与打开对应对话清除、绿点切换、自定义提示及两个菜单的增删、朋友圈本地缓存展示。
