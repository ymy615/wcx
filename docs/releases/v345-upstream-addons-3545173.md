# WCX v345 密友增补版（3545173）

基于上游 v345，修复折叠屏展开后双栏主页的密友显示绿点，并补充微信内部图片分享选择器的密友隐藏。此附件为已经安装验证的 Release 安装包，没有为发布重新编译。

## 下载与安装

- 安装包：`wcx-v345-upstream-addons-3545173-arm64-release.apk`，大小 34,980,815 字节，约 34.98 MB。
- 版本名：`v345-upstream-addons`；版本代码：`3545173`；架构：`arm64-v8a`。
- 构建类型为 `standardRelease`，非调试包，已启用 R8 优化和混淆。
- 与此前本地维护版使用同一签名，可覆盖同签名版本。不同签名的安装包不能直接覆盖安装。
- 安装后保持模块在框架中启用，并重新启动微信；如需完成微信版本适配，按模块提示操作。

## 本次更新

- 微信图片分享的「选择聊天」页中，在密友处于隐藏状态时，同时过滤顶部横向「最近转发」和下方「最近聊天」。密友临时显示时恢复显示。仅过滤本次展示数据，不删除会话或原始转发记录。
- 对该分享页，密友功能总开关开启，且「主页会话隐藏」或「通讯录隐藏」至少一项开启时才进行过滤。
- 修复折叠屏展开时的微信双栏场景：左侧主页仍可见、右侧聊天页取得焦点时，密友临时显示绿点可以继续显示。
- 保留基于上游统一名单的密友增补，包括独立的离开对话与离开主页/切后台恢复隐藏开关、未读提示、显示绿点、标题三击、菜单增删和自定义提示，以及此前的通讯录刷新、会话恢复和朋友圈增补。详情见源码中的 [密友增补文档](../hidden-contact-addons.md)。

## 图片分享隐藏的适用范围

分享选择器依赖微信混淆后的内部接口，因此只对以下经过原始 DEX 核对的准确版本启用：

| 微信版本 | 内部版本号 | 验证情况 |
| --- | --- | --- |
| 8.0.78 | 3180 | 静态接口核对，未实机测试 |
| 8.0.79 | 3182、3200 | 静态接口核对，未实机测试 |
| 8.0.80 | 3220 | 静态接口核对及手机实测 |

**其他版本或内部版本号不会启用这两处分享列表过滤，密友聊天仍可能出现在分享页。** 例如 8.0.79（3183）不在上述范围。这里的限制针对本次新增的分享选择器过滤，并非其他功能的完整兼容性声明。

## 验证范围

- Release 编译成功，APK 非 debuggable，R8 已启用；签名、16 KB ZIP 对齐、303 项注册功能类及所需入口的静态检查通过。
- 微信 8.0.80（3220）上，同一密友在隐藏状态下不出现在图片分享页的顶部最近转发和下方最近聊天；临时显示时两处恢复，再次隐藏后两处再次过滤。普通聊天保留，并核对了两处普通聊天多选时的选择对象；未发送图片。
